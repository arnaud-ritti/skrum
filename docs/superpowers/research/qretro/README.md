# QRetro research

Reference material collected on 2026-09-29 from https://qretro.com (live app, `/docs/*`, `/templates`) and the public repos `qretro/live-cursors`, `qretro/live-reactions`, `qretro/mcp-server`. It is the baseline for the QRetro-parity specs.

| File | Content |
|---|---|
| `research.md` | Condensed notes: board UI, phases, settings, results, poker, games, integrations, MCP |
| `docs-inventory.md` | Feature-by-feature inventory from the public docs (stated vs inferred) |
| `repos.md` | Analysis of the three open-source repos (licences, protocols, limits, MCP tools) |
| `templates.md` | All 52 templates with column titles and descriptions |
| `screens/` | Screenshots from QRetro's docs (third-party images, reference only) |

Spec order agreed on: 1 Board engagement → 2 Retro flow extras → 3 Action items v2 → 4 Planning poker → 5 MCP server → 6 Integrations → 7 Games. LLM features are optional and need a provider key.
